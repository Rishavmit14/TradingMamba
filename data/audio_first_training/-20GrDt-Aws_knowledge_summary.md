## BULLISH INSTITUTIONAL ORDER FLOW

*Teaching time: 10.0 min | Words: 2,000 | Frames: 2*

**Bullish Order Flow = last sell move(s) before buying. Bearish candles that provide buy-side liquidity for SM.**

- In bullish trend, no one wants to sell → SM manipulates retail to sell side
- **Manipulation mechanism**: SM raids previous short-term low (liquidity sweep/grab) → retail sees selling → retail sells → SM buys their sell orders
- SM's sell orders during manipulation remain **pending** → market returns to **mitigate** (close them)
- Where engineered liquidity + bullish order flow coincide = **very strong entry**
- Each new bearish manipulation before continuation = new bullish order flow
- Market mitigates order flow → closes pending orders → continues original direction

## ORDER BLOCK DEFINITION

*Teaching time: 8.0 min | Words: 1,500 | Frames: 3*

**Order Block = refined form of IOF. Collection of pending orders of big banks distributed in blocks.**

- Big banks **DISTRIBUTE** orders in blocks at different levels for premium/discounted prices → maximize profit
- Bearish Order Block = **bullish candle** before a sell move
- Bullish Order Block = **bearish candle** before a buy move
- **Cross-section view**: SM places small pending orders inside the candle → expansion leaves them unmitigated → market returns to close them
- Entry opportunity = when market returns to mitigate the OB (close SM's pending orders)
- OB reduces risk and increases reward ratio compared to trading the full IOF area

## VALID ORDER BLOCK — 2 Rules

*Teaching time: 8.0 min | Words: 1,500 | Frames: 3*

**Only 2 rules determine if an order block is valid. BOTH must be satisfied.**

### Rule 1: Liquidity Sweep
The candle being considered as OB **MUST** take out liquidity of the previous candle or previous high/low.

### Rule 2: Price Imbalance (FVG)
Below that same candle's wick, a **price imbalance (FVG) MUST exist**.

### Invalid Scenarios:
| Scenario | Valid? |
|----------|--------|
| Liquidity swept + FVG present | YES |
| Liquidity swept + NO imbalance | NO |
| NO liquidity sweep + FVG present | NO |
| Invalid pullback (inside candle) + both rules | NO |

### Additional OB Guidelines:
- **50% Rule**: When price returns to mitigate, candle body should NOT close beyond OB's 50% level
- **Trend direction**: OBs in main trend direction = higher probability
- **Inducement filter**: Bullish trend → OB below inducement = high probability. Bearish trend → OB above inducement = high probability

## ORDER BLOCK SMART MONEY TRAPS

*Teaching time: 6.0 min | Words: 900 | Frames: 3*

**Even if both validity rules are met, an OB in inducement/engineered liquidity zone = SMART MONEY TRAP.**

- OB that is part of inducement or engineered liquidity → market will NOT respect it → breaks through
- "Every Order Block, Part of Inducement, Engineered Liquidity will be a SMT"
- Market will break through these OBs regardless of rules being satisfied

### Combined IOF + OB Analysis (Trading Application):
1. Identify bearish/bullish institutional order flow
2. Find the IOF baseline (SM's pending orders)
3. Within the IOF, identify the valid OB using both rules
4. Trade the mitigation of that OB
5. After mitigation, expect trend continuation
