## BOS VALIDATION RULES (Core Teaching)

*Teaching time: 7.0 min | Words: 1,200 | Frames: 3*

**Two fundamental rules determine valid vs fake BOS.**

### RULE 1 — Inducement Required:
- The price swing that breaks structure MUST take inducement from the previous swing FIRST
- Inducement = first valid pullback on left side of the high (V02-V04)
- **For inducement: candle body close is NOT required** — wick sweep is sufficient
- If no inducement taken → BOS is automatically INVALID

### RULE 2 — Candle Body Close:
- After taking inducement, the candle body MUST close ABOVE previous highest candle's WICK
- **For BOS: body close IS required** (unlike inducement where wick is enough)
- If first candle doesn't close above → WAIT for next candle
- If next candle body closes above sweeping candle's high → BOS is VALID
- If no candle closes above → it's a **LIQUIDITY SWEEP**, not BOS

### Four Candlestick Examples (Bullish):

| Example | Inducement | Body Close | Result |
|---------|-----------|------------|--------|
| Top-left | Taken ✓ | Above wick ✓ | **VALID BOS** ✓ |
| Top-right | Taken ✓ | NOT above wick ✗ | **Liquidity Sweep** (not BOS) |
| Bottom-left | Taken ✓ | Next candle closes above ✓ | **VALID BOS** ✓ |
| Bottom-right | Taken ✓ | Neither candle closes above ✗ | **INVALID BOS** ✗ |

### Bearish Market:
- **100% same rules in reverse**: inducement taken + body close BELOW previous lowest candle's wick
