### V6 -- BOS vs Liquidity Sweep vs Swing H/L (Yq-Tw3PEU5U)

**IDM-relevant concept: `three_smc_rules_foundation`**

- "Everything in Smart Money Concepts is based on THREE fundamental rules: Rule 1: Inducement (IDM), Rule 2: Candle Body Close Below Inducement, Rule 3: Candle Body Close Above High."

**IDM-relevant concept: `parallel_comparison_liquidity_sweep_bos_swing`** (THE DEFINITIVE TABLE)

| Concept | Rule 1 (IDM) | Rule 2 (Body Close Below IDM) | Rule 3 (Body Close Above High) |
|---------|-------------|-------------------------------|-------------------------------|
| **Liquidity Sweep** | NOT compulsory | Wick ONLY (body invalidates) | Wick ONLY (body invalidates) |
| **Break of Structure** | MUST take out IDM | Wick OR Body (both valid) | Body MUST close above high |
| **Swing High/Low** | MUST take out IDM | Body ONLY (wick invalid) | Body MUST close above high |

**Critical differences:**
- **IDM requirement:** Liq Sweep = NOT required; BOS = REQUIRED; Swing H/L = REQUIRED
- **Rule 2 flexibility:** Liq Sweep = wick only; BOS = wick OR body; Swing H/L = body only (strictest)
- **Rule 3 strictness:** Liq Sweep = wick only; BOS = body close; Swing H/L = body close

**Key insight:** "BOS and Swing H/L share same IDM rule. Swing H/L is STRICTEST (body close for Rules 2 and 3). Liquidity Sweep is most flexible (no IDM, wick-only)."

- **statistics:** 15 teaching units, 320s duration, 4 frames analyzed, 45 mentions

### File: `/Users/kumarrishav/Desktop/TradingMamba/backend/app/services/smart_money_analyzer.py`

The IDM system is implemented across four tightly coupled methods:

### 5.1 `find_inducement()` (Lines 2332-2545)

**Purpose:** Find inducement zones using full ICT rules from 16-video training.

**ICT Rules Implemented:**
1. IDM = first pullback on left side of swing high/low (Video 1-2)
2. LIQUIDITY SWEEP is THE ONLY confirmation (Video 3)
3. Both wick and body sweeps are valid (Video 3)
4. No sweep = unconfirmed IDM (Video 3)
5. Impulse swing (no pullback) = low/high IS inducement (Video 4 Rule 3)
6. Multiple IDMs: prioritize LARGEST, then MOST RECENT (Video 8)
7. Inducement shifts when new high formed without sweep (Video 4 Rule 1)

**Algorithm (Bullish IDM):**
1. For each swing high, find previous swing low as search boundary
2. Search backward from swing high for pullback candidates (local minima with >0.3% depth)
3. If NO pullbacks found AND previous swing low exists with >0.5% depth: mark as IMPULSE IDM (Video 4 Rule 3)
4. Sort pullback candidates by depth DESC, then index DESC (largest first, most recent tiebreak -- Video 8)
5. Take primary candidate, run `_check_liquidity_sweep()` for validation (Video 3)
6. If primary sweep was wick-only AND secondary pullback exists: also build secondary IDM (Video 4 Rule 2)

**Algorithm (Bearish IDM):** Mirror of bullish -- searches for pullback HIGHs before swing LOWs.

**Output fields per IDM:**
- `type`: bullish/bearish
- `price`, `high`, `low`: IDM zone (price +/- 0.3%)
- `index`, `timestamp`: location in data
- `parent_swing_index`, `parent_swing_price`: which swing this IDM belongs to
- `validity`: valid / unconfirmed / impulse_trap / shifted
- `sweep_type`: body / wick / none
- `is_impulse`: boolean
- `confidence`: 0.4 (unconfirmed) to 0.85 (body sweep)
- `depth`: pullback depth as fraction
- `reasoning`: human-readable explanation chain
- `label`: chart annotation string

### 5.2 `_check_liquidity_sweep()` (Lines 2184-2266)

**Purpose:** ICT Video 3 Rule -- Liquidity sweep is THE ONLY confirmation for valid IDM.

**Reference Candle Rule (Video 3):**
- Bullish: find highest-high candle before pullback -> its LOW is sweep target
- Bearish: find lowest-low candle before pullback -> its HIGH is sweep target

**Algorithm:**
1. Search back up to 10 candles from IDM index for reference candle
2. Find absolute peak (bullish) or trough (bearish) candle
3. Check if pullback candle at IDM index swept through the reference level
4. Classify sweep:
   - `body`: candle body closed beyond reference level (strongest, confidence 0.85)
   - `wick`: candle wicked through but body held (valid, confidence 0.7)
   - `none`: no sweep detected (unconfirmed, confidence 0.4)

**Returns:** `{'type': 'wick'|'body'|'none', 'index': int|None, 'reasoning': list}`

### 5.3 `_build_inducement()` (Lines 2268-2330)

**Purpose:** Build an inducement dict with validation status and per-IDM reasoning.

**Validity Classification:**
- `impulse_trap` (confidence 0.6): impulse swing IDM (Video 4 Rule 3)
- `valid` (confidence 0.85): body sweep confirmed
- `valid` (confidence 0.7): wick sweep confirmed
- `unconfirmed` (confidence 0.4): no liquidity sweep detected

**Builds:**
- Zone width: IDM price +/- 0.3% (tight zone for pin-point accuracy)
- Human-readable reasoning chain
- Chart label with validity tag (checkmark/question mark/lightning bolt)

### 5.4 `validate_swing_points()` (Lines 864-1005)

**Purpose:** Apply ICT 3 SMC Rules (Video 6) to classify each swing as validated/weak/impulse.

**3 SMC Rules for Swing H/L:**
- Rule 1: IDM required (must have inducement before swing)
- Rule 2: ONLY body close below/above IDM (wick-only = weak per Video 6 table)
- Rule 3: ONLY body close above/below previous same-type swing

**Classification Logic:**
- For each swing point, find associated IDMs by `parent_swing_index`
- Pick best IDM: body sweep > wick sweep > none; then largest depth
- Check Rule 3: scan candles between previous same-type swing and current swing for body close beyond
- Classify:
  - `validated` (Strong): All 3 rules met AND not impulse
  - `impulse`: Any IDM is impulse-type (Video 4 Rule 3)
  - `weak`: Has IDM but missing body sweep or body-close-beyond
  - `raw`: No IDM found at all

**Updates swing point fields:**
- `sp.is_validated`: boolean (all 3 rules met)
- `sp.is_strong`: boolean (validated AND not impulse)
- `sp.has_idm`: boolean
- `sp.idm_sweep_type`: body/wick/none
- Per-swing reasoning string with Rule 1/2/3 status indicators

## 7. IDM Master Rule Summary

### The 8 Core IDM Rules

1. **IDM Location** (V1-V2): First pullback (minor swing) on the left side of current high/low
2. **IDM Validation** (V3): ONLY a liquidity sweep confirms valid IDM. No sweep = fake/unconfirmed IDM
3. **Sweep Types** (V3, V6): Both wick-based AND body-based sweeps validate IDM. For BOS, both acceptable. For Swing H/L, ONLY body close (strictest)
4. **IDM Shift Rule 1** (V4): No sweep + new high = IDM shifts to new valid pullback
5. **IDM Shift Rule 2** (V4): Wick-only sweep + new high = sweep swing ALSO becomes IDM (creates multiple levels)
6. **IDM Shift Rule 3 -- THE BIGGEST SECRET** (V4): Impulse swing (no pullback) = the low/high IS inducement, NOT a valid HL/LH. Retail sees CHoCH, Smart Money sees IDM
7. **IDM Selection** (V8): Multiple IDMs -> use LARGEST first, MOST RECENT as tiebreaker
8. **Multi-TF IDM** (V9): Lower TF swing may be higher TF inducement -- breaking it is NOT CHoCH on lower TF

### The Critical Hierarchy

```
IDM exists? -> IDM swept? -> Sweep type (wick/body)? -> Body close beyond previous swing?
    |              |              |                            |
    NO             NO             WICK                        NO
    = raw swing    = unconfirmed  = valid for BOS             = weak swing
    (invalid)      IDM            = INVALID for Swing H/L     (partial validation)
                                  (per Video 6 table)
```

### What IDM Prevents

- **Fake BOS** (V5): breaks without IDM sweep
- **Fake CHoCH** (V9): breaks without IDM taken (Rule 3), lower TF as higher TF IDM (Rule 4)
- **False swing counts** (V2): retail counts every pullback; SMC counts only IDM sweeps
- **Impulse swing traps** (V4): retail misidentifies impulse HL as key support
- **Early entry traps** (V2): entering at IDM instead of waiting for sweep to OB
